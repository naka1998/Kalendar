# Kalendar 要件定義

## 1. プロダクト概要

コンビニ印刷を前提とした、シンプルな壁掛けカレンダーのHTMLを生成するWebアプリケーション。
ユーザーが対話的にレイアウト・画像・祝日・カラーテーマなどを設定し、印刷用HTMLをダウンロードして自分でPDF化・印刷する。

### 1.1 ゴール

- 市販品にない「自分好みのミニマルなカレンダー」を手軽に作れる
- 設定 → プレビュー → ダウンロードの3ステップで完結する
- 技術的知識がなくても使える

### 1.2 基本方針

- **完全クライアントサイド**: バックエンド・DB不要。ブラウザ内ですべて完結する
- **サーバーレスデプロイ**: 静的ホスティングのみで運用可能
- **プライバシー**: アップロード画像・設定データはブラウザ外に送信しない（祝日API取得を除く）

### 1.3 スコープ外

- PDF直接生成（ユーザーがブラウザ印刷でPDF化する前提）
- ユーザーアカウント・クラウド保存
- 複数人での共同編集
- モバイル最適化（PC利用を想定）
